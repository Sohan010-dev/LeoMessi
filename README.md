# 🐐 Lionel Messi – Tribute Website

A sleek, responsive tribute website dedicated to legendary football icon **Lionel Messi**, showcasing his career highlights, achievements, and legacy. Built with modern HTML5 and CSS3, and deployed seamlessly on Vercel.

## ✨ Features

- **Responsive Design:** Fully optimized layout for desktops, tablets, and mobile screens.
- **Media Integration:** Embedded video player showcasing memorable career moments and highlights.
- **Modern Typography & Styling:** Clean layouts, smooth transitions, and subtle hover animations using CSS.
- **Fast Performance:** Pure static website with minimal footprint and zero external JavaScript overhead.

---

## 🛠️ Built With

- **HTML5:** Semantic markup for structured page layout and media embedding.
- **CSS3:** Custom styles, Flexbox/Grid layouts, and responsive breakpoints.
- **Vercel:** Continuous automated deployment via GitHub.
